# Заметка

Аннулирован задним числом — не по качеству реализации, а по составу
архива. Первый прогон тикета 1 через новый Docker-обвязанный харнес
(2026-08-21): к этому моменту `scripts/run-pilot-ticket.sh` ещё не
монтировал одноразовую `~/.claude` внутрь контейнера, поэтому
`transcript.jsonl` в этом архиве нет — сам JSONL-транскрипт сессии был
уничтожен вместе с контейнером (`--rm`). Фикс внесён сразу после
находки, до тикета 2 — см.
[docs/incidents/2026-08-21-write-tool-sandbox-escape/](../../../incidents/2026-08-21-write-tool-sandbox-escape/README.md).
Переигран на той же директории пилота (`pilot-runs-live/python`) с тем
же промптом — см. следующую попытку в этой же `ticket-1/`.

Реализация в `code/` этой попытки была рабочей (юнит-тесты, ручная
проверка `/healthz` — см. `result.json`), инвалидация чисто
инфраструктурная, не о качестве кода.
