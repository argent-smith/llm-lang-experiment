# Копия спецификации для этой попытки не сохранена отдельно

Это первый реальный пилотный прогон эксперимента (2026-08-19) — на тот
момент архивация ограничивалась `prompt.txt`/`result.json`/`stderr.log`
(см. `docs/incidents/2026-08-19-python-ticket1-contamination/`), копия
`SYNCBOX-SPEC.md`, которую агент читал в своей директории, отдельно не
сохранялась и была перезаписана следующей попыткой раньше, чем
появилась практика её архивировать.

Текст, который агент реально видел, восстановим лишь частично — по
цитатам в разборе инцидента
([`README.md`](../../../../incidents/2026-08-19-python-ticket1-contamination/README.md)):

по имени и содержал нарратив про отказ от `network_mode`, раздел
«Критерии приёмки» называл `acceptance/smoke.sh` по пути — оба фрагмента
убраны фиксом, который разбирает тот же документ. Полный текст версии
спецификации ДО фикса нигде не сохранён целиком.
