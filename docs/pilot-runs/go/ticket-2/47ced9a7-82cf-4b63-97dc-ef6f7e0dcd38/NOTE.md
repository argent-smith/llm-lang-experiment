# Заметка

Восстановлено вручную из вывода вызова, зафиксированного в чате
сессии-исследователя, а не автоматической архивацией скрипта — на
момент этого прогона (2026-08-24, Go, тикет 2, раунд с `effort=xhigh`)
`scripts/run-pilot-ticket.sh` использовал `set -euo pipefail` без
перехвата кода возврата `claude -p`: `429 session limit` дал ненулевой
код возврата контейнера, скрипт оборвался раньше строки архивации, и
попытка терялась из `docs/pilot-runs/` целиком, несмотря на то что
`result.json` уже был записан на диск через редирект. `code/` и
`transcript.jsonl` восстановить нельзя —
рабочая директория пилота (`pilot-runs-live/go`) к моменту находки уже
была перезаписана следующей (успешной) попыткой, а транскрипт сессии
жил только в одноразовой, уже уничтоженной директории `~/.claude`
контейнера харнеса.

Фикс — `scripts/run-pilot-ticket.sh` теперь перехватывает код возврата
явно (`|| CLAUDE_EXIT=$?`) и всегда доходит до архивации, возвращая
исходный код вызывающей стороне уже в конце файла (`exit
"$CLAUDE_EXIT"`). См. запись в
[`docs/EXPERIMENT-LOG.md`](../../../EXPERIMENT-LOG.md) и раздел
«Сначала пилот» в [`CLAUDE.md`](../../../../CLAUDE.md) — первый живой
сигнал рейт-лимита в пилоте.
