Вывод автора: по критерию «справился ли агент» эффекта языка нет, различия только в цене успеха; Ruby на Sonnet 5 оказался самым дешёвым из четырёх языков.

Проверки после нашего прогона

  • Базовый образ: все 26 сессий на закреплённых ruby:3.3.12 и ruby:4.0.7, агент ни разу его не сменил.
  • Транскрипты есть у всех 26 сессий.
  • Интернет: 0 обращений к внешним хостам, 0 вызовов субагентов, 0 упоминаний репозитория автора. Единственные совпадения — строка source "https://rubygems.org" в Gemfile.
  • Личных путей и данных в архивах нет.

Ошибки стенда, найденные и исправленные по ходу

  • В образе харнесса был Claude Code 2.1.238, с которым API отклоняет Opus 5.5 (ошибка 400). Версия стала параметром.
  • Проверка транскрипта на macOS падала на русском тексте (tr: Illegal byte sequence), и архив оставался без транскрипта.
  • Контрактный тест искал сервер только на порту из SYNCBOX_PORT. Opus назвал переменные compose-файла иначе, сервер вставал на 8080, и тикет 1 первого запуска впустую сжёг четыре итерации. Первый запуск аннулирован.
  • При полностью зелёном smoke gates.json записывался битым (лишний []).
  • Скрипт разбивки времени падал, если вызов инструмента в транскрипте завершился ошибкой; для двух сессий Ruby 3 разбивка пересчитана.

Ограничения

  • n = 1 на ячейку, как и у автора: различия могут быть шумом единичной генерации.
  • Между нашей кампанией и кампанией автора отличаются сразу модель, effort, версия Claude Code, абзац о версии Ruby в промпте и предзагрузка образа. Чистое сравнение — только Ruby 3.3.12 против Ruby 4.0.7.
  • Время сборки с автором напрямую не сравнимо: у него образ Ruby скачивался во время прогона.
  • Сеть контейнера оставалась открытой; отсутствие выхода в интернет подтверждено по транскриптам, но не гарантировалось заранее. Сетевой запрос из кода, который агент написал и запустил сам, проверка видит не всегда.
  • Стоимость посчитана по ценам API; кампания шла по подписке.
