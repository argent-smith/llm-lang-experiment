Продолжаем проект Syncbox (тикеты 1-2 — каркас сервера и happy path для PUT/GET блоба — уже сделаны в этом же репозитории). Тикет 3: список блобов.

Полная спецификация — в файлах SYNCBOX-SPEC.md и syncbox-openapi.yaml в корне этого репозитория — прочитай перед началом, если нужно освежить детали.

Нужно реализовать:

- GET /blobs — вернуть 200 и JSON-массив объектов {"key", "size", "sha256", "modified_at"} для всех блобов, хранящихся на сервере.
- size — размер в байтах, sha256 — хеш содержимого в hex, modified_at — время последнего изменения в ISO 8601 UTC.
- key — POSIX-путь относительно корня хранилища, включая вложенные директории (например docs/readme.txt), если такие блобы есть на диске.
- Пустое хранилище — пустой массив [], это не ошибка.

Границы этого тикета:

- DELETE /blobs/{key} — отдельный будущий тикет, в этот не входит.
- Защита от directory traversal в key и атомарность записи при параллельных PUT — тоже отдельные будущие тикеты (если ещё не реализованы в текущем коде).

Не реализовывай перечисленное выше заранее — не входит в объём этого тикета.

Сервер по-прежнему должен исполняться в Docker-контейнере через docker compose — не переделывай эту часть, если она уже работает, расширяй по необходимости.

Библиотеки и внутреннее устройство — на твоё усмотрение, как и в предыдущих тикетах.

Версия языка в этом проекте зафиксирована: Ruby 4.0.7, базовый Docker-образ ruby:4.0.7 (FROM ruby:4.0.7 в Dockerfile). Не меняй версию языка и базовый образ.
