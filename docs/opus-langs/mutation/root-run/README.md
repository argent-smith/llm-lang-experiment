# Ночной прогон под root (отвергнут)

Первое измерение 2026-10-06/07: тесты и mutant шли под root внутри образа.
У Opus 5.5 × Ruby 4.0.7 набор тестов под root не прошёл (тесты на права
доступа пропускались, а `ensure`-блок после `skip` падал с ENOENT), поэтому
все пять прогонов переиграны под `nobody` (`scripts/mutation/run-mutant.sh`).
Здесь — только итоги ночных прогонов для оценки воспроизводимости:
та же выборка субъектов (seed 42), те же мутации.
