Syncbox на четырёх языках: Sonnet 5 у автора и Opus 5.5 у нас

Эксперимент llm-lang-experiment: один проект, 11 тикетов с нуля на каждом языке, цикл «реализация → проверки → исправление». Кампания автора — 4–6 сентября 2026 (Sonnet 5, effort xhigh). Наши кампании — 3–4 октября 2026 (Opus 5.5, effort high): Ruby 3.3.12 и 4.0.7, затем Python, JavaScript и TypeScript.

Проверки после наших прогонов

  • Базовые образы: все сессии на закреплённых образах, агент ни разу их не сменил.
  • Транскрипты и разбивка времени есть у всех 63 сессий.
  • Интернет: 0 обращений к внешним хостам, 0 вызовов субагентов, 0 упоминаний репозитория автора.
  • Личных путей и данных в архивах нет.
  • Число ходов пересчитано по транскрипту: Python · Opus 5.5, тикет 11. Агент ждал фоновую задачу, и итоговый JSON учёл только последний отрезок сессии (2 хода вместо 49).

Ошибки стенда, найденные и исправленные по ходу

  • В образе харнесса был Claude Code 2.1.238, с которым API отклоняет Opus 5.5 (ошибка 400). Версия стала параметром.
  • Проверка транскрипта на macOS падала на русском тексте, и архив оставался без транскрипта.
  • Контрактный тест искал сервер только на порту из SYNCBOX_PORT. Opus называет переменные compose-файла иначе, сервер вставал на 8080, и первый запуск кампании Ruby впустую сжёг четыре итерации. Тот запуск аннулирован.
  • При полностью зелёном smoke gates.json записывался битым.
  • Скрипт разбивки времени падал, если вызов инструмента в транскрипте завершился ошибкой.
  • Проверка выхода в интернет давала ложные срабатывания на регулярках вида 127\.0\.0\.1 и на примере адреса nas.lan в README.

Ограничения

  • n = 1 на ячейку: различия между языками и версиями могут быть шумом единичной генерации.
  • Между кампаниями отличаются сразу модель, effort, версия Claude Code, абзац о версии в промпте и предзагрузка образов. Чистые сравнения — языки между собой внутри одной модели и Ruby 3.3.12 против Ruby 4.0.7.
  • Время сборки с автором напрямую не сравнимо: у него часть образов скачивалась во время прогона.
  • Образы Python и Node закреплены плавающими тегами, как у автора; Ruby — точной версией.
  • Сеть контейнера оставалась открытой; отсутствие выхода в интернет подтверждено по транскриптам, но не гарантировалось заранее.
  • Стоимость посчитана по ценам API; наши кампании шли по подписке.
