Продолжаем проект Syncbox (тикеты 1-3 — каркас сервера, happy path для PUT/GET блоба, список блобов со списком и метаданными — уже сделаны в этом же репозитории). Тикет 4: удаление блоба.

Полная спецификация — в файлах SYNCBOX-SPEC.md и syncbox-openapi.yaml в корне этого репозитория — прочитай перед началом, если нужно освежить детали.

Нужно реализовать:

- DELETE /blobs/{key} — удалить блоб по ключу. Если блоб существовал и удалён — вернуть 204 без тела. Если ключа нет — 404.
- key — POSIX-путь относительно корня хранилища, как в предыдущих тикетах.
- После удаления блоб не должен появляться в GET /blobs (список) и GET /blobs/{key} должен возвращать 404.

Границы этого тикета:

- Защита от directory traversal в key — отдельный будущий тикет, в этот не входит.
- Атомарность записи при параллельных PUT — тоже отдельный будущий тикет, не входит.
- Клиентские команды (push/pull/status/sync) — отдельные будущие тикеты, не входят.

Не реализовывай перечисленное выше заранее — не входит в объём этого тикета.

Сервер по-прежнему должен исполняться в Docker-контейнере через docker compose — не переделывай эту часть, если она уже работает, расширяй по необходимости.

Библиотеки и внутреннее устройство — на твоё усмотрение, как и в предыдущих тикетах.

Версия языка в этом проекте зафиксирована: Python 3.12, базовый Docker-образ python:3.12-slim (FROM python:3.12-slim в Dockerfile). Не меняй версию языка и базовый образ.
