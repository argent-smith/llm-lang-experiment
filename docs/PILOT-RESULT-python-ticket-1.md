# Результат пилота: Python, тикет 1

## Итог

Тикет 1 (каркас сервера Syncbox) сошёлся на Python после устранения
методологической контаминации, обнаруженной в первом прогоне. Валидная
точка данных получена; харнесс (`scripts/run-pilot-ticket.sh`) готов к
переиспользованию на следующих тикетах и языках.

Агент прочитал `acceptance/reference-impl` этого метарепозитория через
обычный Bash/Read и почти дословно скопировал оттуда архитектурные
решения. Подтверждено буквально в его же итоговом отчёте: *«следует
проверенному паттерну из `acceptance/reference-impl`»*. Полный разбор —
[`docs/incidents/2026-08-19-python-ticket1-contamination/`](incidents/2026-08-19-python-ticket1-contamination/README.md).

**Корневая причина** — два независимых фактора одновременно:

1. `SYNCBOX-SPEC.md` называл и описывал `acceptance/reference-impl` по
   имени.
2. `--safe-mode` отключает CLAUDE.md/хуки/скиллы, но не ограничивает
   файловую систему.

## Фиксы

| #        | Фикс                    | Механизм                                                                                                                       |
| -------- | ----------------------- | ------------------------------------------------------------------------------------------------------------------------------ |
| 1        | Скраб `SYNCBOX-SPEC.md` | Убраны все пути и нарратив про reference-impl; убрано упоминание сравнения шести языков (демид-характеристика)                 |
| 2        | Файловая песочница      | `sandbox.filesystem.denyRead`/`allowRead` через `--settings <файл>` в `scripts/run-pilot-ticket.sh`, `failIfUnavailable: true` |
| 3 (доп.) | Чистка Docker-демона    | Перед каждым вызовом удаляются образы/контейнеры/сети с префиксом `syncbox` — закрывает утечку имён через `docker images`      |

Фикс 2 проверен тремя дешёвыми диагностическими прогонами (~$0.66) до
реального тикета: чтение метарепозитория блокируется, своя директория
доступна, loopback и `docker pull`/`build` работают штатно.

`llm-lang-experiment`/`reference-impl`. Реализация архитектурно

trap/backgrounding) — качественный сигнал в пользу отсутствия
копирования. Функционально проверено вручную: `/healthz` → 200 через
флаги и через переменные окружения, чистый teardown по сигналу.
