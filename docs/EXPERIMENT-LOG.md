# Журнал прогонов

Одна строка на попытку прогона тикета (не на тикет — при «сдался» и
повторном запуске после фикса заводится новая строка). Поля — см.
раздел «Лог» в [CLAUDE.md](../CLAUDE.md). Разбор отдельных инцидентов —
в [docs/incidents/](incidents/). Промпт, копия спецификации и полный
`result.json` каждой попытки — в [docs/pilot-runs/](pilot-runs/), не
только сводка здесь.

«Время (API/инфра/работа)» — минуты, разбивка суммарного «Время» на три
составляющих через `scripts/analyze-timing-breakdown.py`:
**API** — `duration_api_ms` из `result.json`, время именно на вызовы
модели (уже готовое поле Claude Code, не наша оценка); **инфра** —
холодная загрузка Docker-образов и установка зависимостей (`docker
pull`, `apt-get`/`opam install`/`bundle install`/`npm install`/`sbt
update`/`go mod download` и т. п.), определяется построчным разбором
`transcript.jsonl` и вывода сборки (BuildKit- и classic-формат);
**работа** — остаток инструментального времени (штатные тесты,
компиляция написанного агентом кода, отладочные команды,
curl-проверки) — не
независимая сумма, а `(Время − API) − инфра`, чтобы не накапливать
дрейф от построчного тайминга. Посчитано только для 21 канонического
тикета (см. `docs/PILOT-COMPARISON-all-languages.md`); на остальных
строках — «н/д» (не пересчитывалось для superseded/аннулированных
попыток). Метод и известные ограничения (эвристика по ключевым словам,
не AST Dockerfile; `tail -N` в командах агента может обрезать признаки
установки в логе) — в докстринге самого скрипта.

Code security пробовали (bandit для Python, gosec для Go) и убрали:
сравнение находок между языками оказалось неинформативно для гипотезы
эксперимента — числа отражали в первую очередь разное покрытие правил
между инструментами (`bandit` не ловит path traversal из коробки,
`gosec` ловит), а не разницу в безопасности кода. Разбор —
[`docs/PILOT-COMPARISON-python-go.md`](PILOT-COMPARISON-python-go.md#code-security-исключено).

«Итерации» здесь — число вызовов `claude -p`/`--resume` в цикле
реализация → саморевью → фикс, не `num_turns` внутри одного вызова
(вызов выше был единственным, `num_turns=42` — это внутренние шаги
одного вызова, а не отдельные итерации цикла).
