## Текст

Наверняка вам знакома ситуация: агент на Ruby-тикете в десятый раз находит у себя новую придирку в саморевью, а коллега на Python тем временем уже закоммитил и ушёл на обед. Очевидное объяснение — модели неравнодушны к языку программирования не по его достоинствам, а по объёму кода в обучающей выборке: Python в фаворе как язык самих авторов LLM, JavaScript и TypeScript — просто по массовости, а Ruby не проходит ни по одному критерию и должен проигрывать по обоим. Я взялся это проверить, а не пересказать в сотый раз. Собрал тестовый сетап: связка Claude Code headless и `claude-sonnet-5` держится постоянной, а модель «пишет маленькую программку» на подозреваемых языках — Python, JavaScript, TypeScript, Ruby. Каждый вариант (сервис синхронизации файлов Syncbox) собирается с нуля по единой спецификации и крутится в цикле «реализация — саморевью — три гейта (тесты, смок, контракт) — фикс — повтор» до сходимости или отказа.

Первые же опыты показали, что первоначальная гипотеза оказалась несколько наивной. Об ожидаемых и неожиданных находках милости прошу узнать на докладе. Дисклеймер: это первое исследование и первый доклад в моей новой серии об агентной разработке. Продолжение будет, и оно обещает быть интересным.
