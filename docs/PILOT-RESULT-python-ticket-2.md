# Результат пилота: Python, тикет 2

## Итог

Тикет 2 (PUT/GET блоба, happy path) сошёлся на Python. Первый прогон
пришлось аннулировать (устаревшая копия спецификации), второй —
отклонён самим харнессом до единой строчки кода (флаг разрешений), и
только третий стал валидной точкой данных на тогдашнем харнессе.
Подробности обеих находок — в отдельных инцидентах, здесь только итог
по тикету. Прогон 3 задним числом аннулирован 2026-08-24 — весь пилот
Python+Go переигран на Docker-обвязанном харнессе (см.
[инцидент](incidents/2026-08-21-write-tool-sandbox-escape/README.md)).
Прогон 4 (2026-08-24) тоже аннулирован задним числом 2026-08-25 — тот
раунд использовал `effort=high` вместо `xhigh` (харнес не фиксировал
`--effort` явно). **Действующая точка данных — прогон 5** ниже.

частичной реализации он бы валил не баги тикета 2, а недоделанные
куски будущих тикетов. Оба скрипта станут содержательными начиная
примерно с тикета 4–6 (после чего реально можно будет проверить риск
3 — устойчивость цикла `-p` → `--resume` к внешней обратной связи).
