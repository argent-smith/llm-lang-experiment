# Результат пилота: Python, тикет 2

## Итог

Тикет 2 (PUT/GET блоба, happy path) сошёлся на Python. Первый прогон
пришлось аннулировать (устаревшая копия спецификации), второй —
отклонён самим харнессом до единой строчки кода (флаг разрешений), и
только третий стал валидной точкой данных. Подробности обеих находок —
в отдельных инцидентах, здесь только итог по тикету.

попыталась обойти ограничение. См.
[инцидент](incidents/2026-08-20-dontask-permission-denial/README.md).

| Исход                                 | **сошлось**                            |

Скан транскрипта — 0 совпадений по всем проверяемым терминам. Штатных
тестов не писал, проверял вручную через `run-server` + `curl`: PUT/GET
в корне и во вложенной директории, перезапись существующего ключа,
побайтовое сравнение бинарных данных (2 KB `/dev/urandom`), 404 на
отсутствующий ключ.

**Смок/контракт по-прежнему не применимы** — не специфика этого
тикета, а ограничение самих скриптов на данном этапе бэклога:
`acceptance/smoke.sh` требует `run-client`, которого не будет до
тикета 7; `acceptance/contract-test.sh` гоняет Schemathesis по полной
`syncbox-openapi.yaml`, включая эндпоинты (список блобов, DELETE,
защита от traversal), которые появятся только в тикетах 3–6 — на
частичной реализации он бы валил не баги тикета 2, а недоделанные
куски будущих тикетов. Оба скрипта станут содержательными начиная
примерно с тикета 4–6 (после чего реально можно будет проверить риск
3 — устойчивость цикла `-p` → `--resume` к внешней обратной связи).
